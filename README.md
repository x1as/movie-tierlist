# Кинотир

Тирлист фильмов, мультиков и сериалов: 735 позиций (291 из списка Xias + 444 рекомендации по его вкусу).

- **Тирлист**: drag & drop, клик по постеру или горячие клавиши (`S A B C D X`, `0` вернуть в коробку).
- **Итоги**: кино-тип из четырёх букв, шкалы вкуса, рейтинг жанров, форматов и эпох.
- **Выгрузка и загрузка**: код `KT1.…` (deflate + base64url) или `.json`.
- **Секретная комната** `#/xias-mirror`: сравнение чужой выгрузки с тирлистом Xias.

Всё хранится в localStorage, бэкенда нет.

## Команды

```bash
npm i
npm run dev
npm run build
node scripts/set-default.mjs "KT1.…"   # сделать выгрузку тирлистом по умолчанию
node scripts/fetch-posters.mjs          # докачать постеры новых фильмов (Википедия)
node scripts/fetch-tvmaze.mjs id1,id2   # постеры сериалов с TVmaze
```

Новый фильм: строка в `src/data/movies.ts` (id не менять, на них держатся выгрузки), затем `fetch-posters`.

Деплой: `npm run deploy` (собирает и пушит в ветку `gh-pages`).

Постеры: Википедия и TVmaze.
